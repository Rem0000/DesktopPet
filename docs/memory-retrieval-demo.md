# 记忆检索手工演示脚本（5–10 条）

在聊天窗按顺序发送，并打开「长期记忆」面板观察 pin / 搜索 / 跨会话召回。

1. `请记住我叫阿哲，职业是前端工程师。`
2. `记住一个事实：我养了一只叫豆豆的橘猫。`
3. `再记住：我平时不喝咖啡，更喜欢绿茶。`
4. 打开长期记忆 → 搜索 `橘猫`，应只看到相关条目。
5. 将「绿茶」那条点「置顶」。
6. 新建会话后问：`我养了什么宠物？叫什么名字？` —— 应能答出豆豆/橘猫。
7. 问：`我饮料偏好是什么？` —— 置顶的绿茶应更容易被引用。
8. 说：`忘掉我养橘猫这件事。`（或面板手动删除）后再问宠物，应不再坚称橘猫。
9. 切换另一个 Live2D 模型会话，问：`我的职业是什么？` —— 画像应跨模型仍可用。
10. （可选）在工具时间线中确认出现 `update_profile` / `remember_fact` / `forget_memory` 调用与耗时。
