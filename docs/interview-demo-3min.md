# 3 分钟项目演示脚本（秋招）

目标：工具链 → 记忆检索 → RAG 引用。

## 准备
1. 启动桌宠与聊天窗，配置 DeepSeek API Key。
2. 打开「知识库」→ 导入 `docs/rag-demo.md`。
3. 本轮工具调用时间线**默认展开**，可直接指出工具名与耗时（无需手动展开）。

## 演示顺序（约 180 秒）

1. **工具链（60s）**  
   发送：`请记住我叫阿哲，职业前端；另外 3 分钟后提醒我喝水。`  
   指出时间线中的 `update_profile` / `remember_fact` / `schedule_reminder` 与耗时；工具执行中气泡会显示「正在调用工具…」。

2. **记忆检索（60s）**  
   打开长期记忆 → 搜索「阿哲」→ 将某条置顶。  
   新建会话问：`我是谁？做什么工作？` —— 展示 Hybrid 检索跨会话召回（BM25 + 本地 BGE 向量）。

3. **RAG 引用（60s）**  
   发送：`根据本地知识库，这个项目秋招路线里有哪些能力？`  
   指出 `search_knowledge` 调用与气泡下「引用来源」（可折叠）；强调无命中不会假引用。数据与模型权重均在项目 `data/` 目录。

可选加分：让桌宠「忘掉」某条记忆 → 聊天顶栏弹出 confirm 确认框，拒绝则不删除。

## 收尾一句话
「这是端侧可控的 Agent：工具可注册可观测、记忆可检索、资料可引用，而不是只调 Chat Completions。」
