|---|---|
| `messageImportance.ts`（新） | `scoreMessageImportance`（用户关键事实/提问/长消息/数字 → 3，寒暄 → 1，默认 2；助手带成功工具 → 3）；`trimContextWeighted`（近期窗口逐字 + 窗口外按 importance 高→低补齐、保序、恒保最新） |

| `agentRuntime.ts` / `memoryService.ts` | `trimContext`/`trimToBudget` 统一走 `trimContextWeighted` |
| `chatController.ts` | `loadContextConfig` 传入 runtime；实例化 `EpisodeDistiller` 以串行队列 + AbortController 接入 `onChatComplete` |

## 三、助手 Markdown 安全渲染

**改动**（renderer 侧）：

| 文件 | 说明 |
|---|---|
| `package.json` | 新增 `react-markdown@^10` + `remark-gfm`（renderer 依赖，Vite 打包，不进主进程 external/asarUnpack） |
| `src/chat/MarkdownView.tsx`（新） | `ReactMarkdown` + `remarkPlugins:[remarkGfm]`；`components` 映射 `<a target=_blank rel=noreferrer>`、`<pre>/<code>` 横向滚动；raw HTML 默认转义（不产生可执行 DOM）；渲染异常回退纯文本 |
| `src/chat/ChatApp.tsx` | `role==='assistant' && status!=='streaming' && content` → `<MarkdownView>`；其余（用户/流式/空）走纯文本 `<div className="message-plain-text">` |
| `src/chat/chat.css` | `.message-bubble` 去掉全局 `pre-wrap`，限定到 `.message-plain-text` / `.markdown-plain-fallback` / user 气泡；新增 `.markdown-body` 全套排版（标题/列表/引用/行内代码/围栏代码块/表格/链接） |
| `vitest.config.ts` | include 补 `src/**/*.test.tsx` |

**关键决策**：流式期不渲染 Markdown（每 token 全量 parse + 滚动抖动），完成态一次渲染（`message.status` 已提供信号）；raw HTML 用 react-markdown 默认转义而非 sanitizer（从根上避免 LLM 输出进 DOM，符合 CSP）。

**测试**：`MarkdownView.test.tsx`（6，用 `renderToStaticMarkup`）；`npm test` 全量 201 通过，typecheck 通过，`npm run build` 成功。
