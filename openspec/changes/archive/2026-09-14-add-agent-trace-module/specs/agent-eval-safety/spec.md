## MODIFIED Requirements

### Requirement: 敏感信息遮罩

系统在工具观测日志、会话链路日志、时间线详情、链路追踪台界面与评测输出中 MUST 对疑似 API Key、密码、令牌等敏感片段进行遮罩；遮罩失败时 MUST 宁可截断也不完整落盘明文密钥。遮罩范围 MUST 覆盖链路日志的全部字段（含工具入参、工具输出、系统提示词、模型文本与错误信息）以及外置原文文件；链路导出副本 MUST 再次执行遮罩。

#### Scenario: 日志遮罩密钥
- **WHEN** 工具入参或错误信息包含疑似密钥模式
- **THEN** 持久化日志与 UI 详情中对应片段被替换为遮罩文本

#### Scenario: 外置原文同样遮罩
- **WHEN** 工具输出因超过单字段上限被外置存储，且内容包含疑似密钥
- **THEN** 外置原文中的敏感片段同样被遮罩，追踪台展开时不可见明文

#### Scenario: 导出副本再遮罩
- **WHEN** 用户导出某会话链路
- **THEN** 导出文件中的敏感片段已遮罩，且不影响原始日志

## ADDED Requirements

### Requirement: 轨迹忠实性评测

离线评测 SHALL 覆盖链路追踪的忠实性，至少断言：每次模型调用都有 token 用量记录或带估算标记；工具事件记录的入参与输出与该次真实执行一致（不得为占位符或空值）；被取消或失败的轮次具有明确终态；链路写入失败时对话仍正常完成；含疑似密钥的入参不以明文落盘。

#### Scenario: 用量必有记录
- **WHEN** 评测场景执行一次包含工具调用的对话
- **THEN** 断言该轮每次模型调用均有用量记录或估算标记，且轮次汇总用量等于各次调用之和

#### Scenario: 参数与结果忠实
- **WHEN** 评测场景执行带结构化入参的工具调用
- **THEN** 断言链路事件中的入参与输出与真实执行一致，且非空占位

#### Scenario: 终态明确
- **WHEN** 评测场景模拟用户取消或 provider 报错
- **THEN** 断言该轮具有取消或失败的终态事件，且此前事件保留

#### Scenario: 落盘失败不影响完成
- **WHEN** 评测场景令链路日志目录不可写
- **THEN** 断言对话仍返回完整回复，且未抛出异常

#### Scenario: 密钥不落明文
- **WHEN** 评测场景传入含疑似密钥的工具入参
- **THEN** 断言链路日志、外置原文与导出内容中均不存在该明文
